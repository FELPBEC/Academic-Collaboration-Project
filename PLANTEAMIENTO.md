# MANEJO DE CLASES
## PARA LOS PARTICIPANTES (VERTICES)
- Se hara una clase user que tendrá los roles tanto de profesores, estudiantes, semilleros y grupos de trabajo
- También un  identificador, nombre, tipo de participante, programa y área de
interés.
- Los roles se manejan con un Enum
- El acceso es mediante correo institucional 
- Limitar las opciones de determinar el programa institucional y área de interés 
## PARA LAS RELACIONES (ARISTAS)
- El tipo de relación será un Enum 
- "EN DUDA" El tipo de relación tendrá un valor de "peso" para determinar la cercanía de las interacciones y con eso determinar cercanía entre dos usuarios
